> **Pioneering the future through cutting-edge research.**  
> Nova R&D is a demo landing page for a fictional Research & Development firm specializing in AI, Biotechnology, and Quantum Computing.

---

## ✨ Features

- **Modern Dark Theme** — Sleek, dark UI with neon gradient accents
- **Fully Responsive** — Works on all devices (mobile, tablet, desktop)
- **Animated Particles** — Dynamic background particle system
- **Scroll Animations** — Elements fade in as you scroll
- **Live Counters** — Animated statistics (publications, patents, etc.)
- **Interactive Form** — Contact form with visual feedback
- **Team Cards** — Researcher profiles with social links
- **Project Showcase** — Active, completed & upcoming projects
- **Cursor Glow** — Interactive mouse glow on desktop

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Structure & SEO |
| CSS3 | Styling, grid, animations |
| Vanilla JS | Interactivity, particles, counters |
| Font Awesome | Icons |
| Google Fonts | Inter & JetBrains Mono |
| DiceBear | Avatar generation |
| GitHub Pages | Hosting |

## 🧬 Sections

1. **Hero** — Animated intro with stats counters
2. **About** — Mission, Vision & Values
3. **Research** — Three pillars: AI, Biotech, Quantum
4. **Projects** — Featured research projects
5. **Team** — Key researchers with avatars
6. **Stats** — Publication & patent metrics
7. **Contact** — Inquiry form with subject selection
8. **Footer** — Links, social media, legal
